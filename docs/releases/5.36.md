# Payload 5.36 / Launcher 5.48

Fix a reproducible final-synthesis control-file sharing race that could abort synthesis with Windows error 32 and leave the game open under the existing fail-closed shutdown guard.

Control-file readers now share rename/delete access. Complete sibling files replace the visible record without deleting it first; transient sharing conflicts receive a bounded 250 ms retry. Persistent contention still fails closed without changing permissions. Each heartbeat publication refreshes control/time, and the child rechecks its held parent process after a delayed read.

PAUSE/STOP are rechecked across the new I/O waits. Verified successful synthesis remains recorded, but paused/stopped runs do not authorize shutdown and resumed runs do not repeat synthesis.

No changes to fusion-count decisions, game inputs, restart limits, server completion, Caps Lock protection, website or API behavior. Launcher and Payload are rebuilt together; the unchanged server bundle remains 1.0.88.

Release validation uses the existing Background profile while the user's game remains active. Six native tests requiring stopped production are deferred. Publishing this release does not install it into or restart an already-running device; live final-synthesis/shutdown acceptance remains separate.
