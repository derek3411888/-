# Payload 5.38 / Launcher 5.50

Fix a fresh-launch guard regression reproduced on MYDESKPC: WMI can omit the executable path of an unrelated background process. The launcher now uses a query-only retained process handle to verify its actual image, executable name, liveness and creation time against the original WMI record. An unrelated process no longer blocks launch merely because WMI omitted its image. Missing command lines and unverified ownership remain fail-closed; no broad process termination is introduced.

Temporary incomplete inventory or a still-finalizing recording is retried within the existing drain budget. Close actions occur only after a complete, verifiable inventory. Persistent unknown ownership, inventory failure, denied close and overdue inventory results still block replacement safely. Restart/resume/next-server ownership, existing protection limits, recording finalization, game login and synthesis behavior are unchanged.

Launcher and Payload are rebuilt together. Website/API sources and server version 1.0.88 are unchanged. Release verification includes background regression, current/legacy isolated takeover with a missing-image fixture, restart handoff, compiled embedding and archive/source/hash consistency. Six production-dependent native tests remain deferred while active games are protected. Publication does not prove installation or live gameplay acceptance and does not restart either device.
