# Payload 5.33 / Launcher 5.45 / Server 1.0.88

## Included

- Both remote-control websites receive an Apple-style responsive interface while retaining functional controls, existing transports, keyboard navigation, and low-overhead updates.
- Selected-device `RESTART_UPDATE` uses durable nonce/ACK and STOP priority, closes only verified managed processes, finalizes recording, and resumes through the formal updater. It is not a Windows reboot. Old clients without the same-build capability cannot receive this command.
- Reward-completion handling performs one verified synthesis before closing or switching servers. Durable success and completion receipts prevent premature shutdown and duplicate synthesis after recovery.
- The account-login correction from Payload 5.32 remains included in both the external ZIP and the launcher's embedded ZIP.

## Validation and deployment boundary

- Background regression: 67 test files passed; 21 isolated restart-handoff scenarios passed; website/server tests: 140 passed.
- Six tests requiring stopped production remain deferred. No production game control or device restart was performed for this release verification.
- Every packaged entry was compared with the isolated release source; the launcher's embedded ZIP matches the external `payload.zip`.
- GitHub publication and Pages deployment must be verified separately. Central deployment requires migration `011_restart_update_command.sql` and matching server/web identity; publication alone does not prove central installation or device update.

Unrelated in-progress Codex bridge/installer changes and user VS Code/OCR changes are excluded. Existing central support cooldown behavior is retained. This release does not restart Docker, Windows services, or active farming sessions.
