# 自動開啟OKWW - 修復打包EXE後重複啟動問題

## 問題

打包成EXE後啟動器會開啟兩個OKWW實例。

## 解決方案

1. 添加了全域互斥量確保即使打包為EXE也只會有一個實例運行
2. 增強了窗口檢測和進程管理邏輯
3. 添加了更詳細的日誌記錄
4. 改進了啟動前後的進程檢查
5. 擴展了OKWW窗口的搜尋條件

## 如何使用

直接執行腳本或打包為EXE:

```
AutoHotkey64.exe 自動開啟OKWW.ahk
```

## 主要變更

- 添加了全域互斥量 `OKWW_AutoUpdater_SingleInstance`
- 改進了進程檢測和窗口搜索邏輯
- 添加了更詳細的日誌輸出
- 改進了錯誤處理
- 擴展了OKWW窗口的搜尋條件

## 診斷

如果還有問題，請檢查 `okww.log` 日誌文件中的詳細記錄。
